# ADR-0006: UIデザイン方針 — Spotify Midnight（ダークグラスモーフィズム）

## ステータス

Accepted

## コンテキスト

TuneCardのUIはTailwind CSSのデフォルトユーティリティ（gray-50/gray-900）を使っただけの無個性なデザインだった。公開アプリとしての第一印象が弱く、音楽アプリらしさがなかった（Issue #10）。

WEB調査で3つの方向性を検討した:
- **案A: Spotify Midnight** — ダークグラスモーフィズム
- **案B: Vinyl Warm** — 暖色アクセントのミニマル
- **案C: Neon Pulse** — ネオングロー

## 決定

**案A「Spotify Midnight」を採用**する。

### デザインシステム
- **背景**: ダークモードは `gray-950` + Spotifyグリーンのグラデーションブロブ
- **カード**: グラスモーフィズム（`backdrop-blur-xl` + `bg-white/5` + `border-white/10`）
- **ボタン**: `rounded-full` + `active:scale-95` + ホバーグロー
- **アクセント**: Spotifyグリーン `#1DB954`
- **アイコン**: Lucide React（絵文字から移行）
- **アニメーション**: カード出現時のスライドアップ、スケルトンローディング

## 理由

- Spotifyのダーク基調UIとの親和性が最も高い
- グラスモーフィズムは2025-2026年のトレンドで、楽曲カードのような「一時的に表示されるレイヤー」に適している
- Tailwind CSSのユーティリティクラスだけで実現でき、追加CSSライブラリが不要
- ライトモード/ダークモードの両対応が自然にできる
- 案Bは Spotifyブランドとの親和性が低く、案Cはやりすぎるとゲーム系UIに見えるリスクがあった

## 結果

- 全コンポーネントのスタイルをグラスモーフィズムベースに統一
- Lucide Reactを依存に追加（tree-shakeable、必要なアイコンのみバンドル）
- カスタムアニメーション（slideUp）をindex.cssに追加
- スピナーをスケルトンUIに置き換え
